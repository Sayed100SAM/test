# SayedCart Grocery eCommerce Homepage

A responsive Laravel-ready grocery eCommerce homepage built with Blade, Tailwind CSS, Alpine.js, Swiper.js, AOS and Laravel Vite.

## Requirements

- PHP 8.3+
- Composer
- Node.js 20+
- Laravel 11+

## Setup

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
npm run dev
php artisan serve
```

## Build

```bash
npm run build
```

## Main files

- `resources/views/layouts/app.blade.php`
- `resources/views/pages/home.blade.php`
- `resources/views/components/*`
- `resources/views/sections/*`
- `resources/css/app.css`
- `resources/js/app.js`
